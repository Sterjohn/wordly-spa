# Wordly — Dictionary App

A Single Page Application built with HTML, CSS, and JavaScript.

## Features
- Search for any English word
- Displays definitions, part of speech, and example sentences
- Phonetic pronunciation text
- Audio playback for pronunciation
- Clickable synonyms that trigger a new search
- Error handling for invalid or misspelled words

## Technologies Used
- HTML
- CSS
- JavaScript
- [Free Dictionary API](https://dictionaryapi.dev/)
